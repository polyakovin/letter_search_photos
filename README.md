# Letter Search Photos

Content-репозиторий игры «Найди на букву…».

- UUID-файлы в корне — опубликованные картинки, доступные боту через GitHub
  Pages по адресу `https://polyakovin.github.io/letter_search_photos/<uuid>.jpg`.
- [`catalog.md`](./catalog.md) связывает известные исторические названия, посты и
  UUID.
- [`drafts/`](./drafts/) содержит перенесённую очередь непубликованных картинок.
- [`source-prompts.md`](./source-prompts.md) сохраняет ранние механики, списки
  слов и prompts для части изображений.

Draft нельзя перемещать в корень или публиковать без проверки слов, играбельности
и записи новой игры административным ботом: production ожидает UUID, созданный
приложением.
